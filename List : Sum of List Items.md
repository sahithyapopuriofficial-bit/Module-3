# List Operations in Python: Sum of List Items

## 🎯 Aim
To write a Python program that calculates the **sum of all elements** ending with 3 in a list.

## 🧠 Algorithm
1. Define a list of numbers.
2. Use looping Statements to list out the numbers ending with 3
3. Append the elements into the list.
4. Use Python’s built-in `sum()` function to calculate the total.
5. Print the result.

## 🧾 Program
```
lst=eval(input())
total = 0
for num in lst:
    if num%10==3:
        total += num
print("Sum=", total)

```
